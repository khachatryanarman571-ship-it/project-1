Հակիրճ տեղեկատվություն C++-ի վերաբերյալ

C++-ը ընդհանուր նշանակության, բարձր արդյունավետությամբ ծրագրավորման լեզու է։ Այն ստեղծվել է Bjarne Stroustrup-ի կողմից՝ որպես C լեզվի ընդլայնում։ C++-ը աջակցում է ինչպես պրոցեդուրալ, այնպես էլ օբյեկտակողմնորոշված և generic ծրագրավորմանը։
Հիմնական առանձնահատկությունները Բարձր արագություն և արդյունավետություն — հաճախ օգտագործվում է այն ծրագրերում, որտեղ կարևոր է կատարողականությունը։ Օբյեկտակողմնորոշված ծրագրավորում (OOP) — դասեր, օբյեկտներ, ժառանգում, պոլիմորֆիզմ և այլն։ STL (Standard Template Library) — պատրաստի տվյալների կառուցվածքներ և ալգորիթմներ, օրինակ՝ vector, map, set, sort։ Հիշողության կառավարում — հնարավոր է աշխատել հիշողության հետ ցածր մակարդակով։ Բազմաթիվ կիրառություններ — խաղեր, օպերացիոն համակարգերի բաղադրիչներ, desktop ծրագրեր, ներդրված համակարգեր, բարձր արտադրողականությամբ ծրագրեր և այլն։
Ի՞նչ սովորել C++-ում Եթե սկսում ես զրոյից, լավ հերթականություն է՝ Փոփոխականներ և տվյալների տիպեր if, else, switch for, while, do while Ֆունկցիաներ Զանգվածներ և string Ցուցիչներ և հղումներ struct և class OOP STL (vector, map, set, queue, stack և այլն) Ալգորիթմներ և տվյալների կառուցվածքներ Եթե ցանկանում ես, կարող եմ նաև C++-ը սովորեցնել զրոյից՝ դաս առ դաս, պարզ բացատրություններով և վարժություններով։
